# MemoriesStore 部署操作手册

本文记录将服务端部署到家中 iMac，并通过云服务器 FRP 对外提供访问的完整做法（基于首次落地实操整理）。

## 1. 架构概览

```
公网客户端
    │
    ▼
云服务器 120.48.22.80
  ├─ frps :7000          （FRP 控制端口）
  ├─ :6000  ──FRP──► iMac:22        （SSH）
  └─ :10002 ──FRP──► iMac:10002     （MemoryStore HTTP）
                         │
                         ▼
              家中 iMac（内网）
              /Users/fengtianyu/Projects/MemoriesStore/server
              media → /Volumes/Library/MemoriesStore
```

| 角色 | 说明 |
|------|------|
| 运行机器 | 家中 iMac |
| 项目路径 | `/Users/fengtianyu/Projects/MemoriesStore` |
| 照片/视频存储 | `/Volumes/Library/MemoriesStore`（外接盘） |
| 元数据（SQLite 等） | `server/data/`（本机磁盘） |
| 本机监听 | `0.0.0.0:10002` |
| 公网入口 | `http://120.48.22.80:10002` |
| FRP 客户端目录 | `/Users/fengtianyu/Projects/frp_0.70.0_darwin_arm64` |
| FRP 守护进程 | `/Library/LaunchDaemons/com.frpc.plist`（开机自启） |

## 2. 前置条件

1. 外接盘已挂载为 `/Volumes/Library`，并存在可写目录 `/Volumes/Library/MemoriesStore`
2. 云服务器已安装并运行 `frps`（`bindPort = 7000`）
3. 云服务器安全组 / 防火墙已放行：
   - `7000/tcp`（FRP）
   - `6000/tcp`（SSH 穿透）
   - `10002/tcp`（MemoryStore 穿透）
4. iMac 可访问公网，且已安装 Go（建议 ≥ 1.25；构建 1.26 依赖时可用 `GOTOOLCHAIN=auto`）
5. 本机可通过 FRP SSH 登录 iMac：

```bash
ssh -p 6000 fengtianyu@120.48.22.80
```

## 3. 修改服务配置

编辑 iMac 上的配置文件：

`server/configs/config.example.yaml`

关键项：

```yaml
server:
  listen: "0.0.0.0:10002"
  public_base_url: "http://120.48.22.80:10002"

data:
  root: "./data"
  media_root: "/Volumes/Library/MemoriesStore"
```

说明：

- `listen` 必须是 `0.0.0.0`，否则 FRP / 局域网都连不上；本机与公网统一使用 `10002`
- `public_base_url` 用于分享链接等对外地址，填公网入口
- `media_root` 指向外接盘；SQLite 等仍放在 `data.root`

## 4. 配置 FRP 端口映射

编辑 iMac：

`/Users/fengtianyu/Projects/frp_0.70.0_darwin_arm64/frpc.toml`

完整示例：

```toml
serverAddr = "120.48.22.80"
serverPort = 7000

[[proxies]]
name = "ssh"
type = "tcp"
localIP = "127.0.0.1"
localPort = 22
remotePort = 6000

[[proxies]]
name = "memorystore"
type = "tcp"
localIP = "127.0.0.1"
localPort = 10002
remotePort = 10002
```

修改后需重启 `frpc`。该机由 LaunchDaemon 托管，推荐：

```bash
# 会短暂断开当前 SSH（走 FRP），LaunchDaemon 会自动拉起新配置
sudo kill "$(pgrep -f '/Projects/frp_0.70.0_darwin_arm64/frpc')"
# 等待数秒后重新 SSH
```

成功标志（`frpc.log`）：

```text
proxy added: [memorystore ssh]
[memorystore] start proxy success
[ssh] start proxy success
```

## 5. 编译与启动服务

### 5.1 编译（在 iMac 上）

国内网络建议使用代理，并允许自动拉 Go toolchain：

```bash
cd /Users/fengtianyu/Projects/MemoriesStore/server
export PATH="/usr/local/go/bin:/opt/homebrew/bin:$PATH"
export GOPROXY=https://goproxy.cn,direct
export GOSUMDB=sum.golang.google.cn
export GOTOOLCHAIN=go1.26.0   # 或 auto

go build -o ./bin/memorystore ./cmd/memorystore
```

### 5.2 规避 macOS Gatekeeper 卡住

从别处拷贝来的二进制可能带 `com.apple.quarantine`，启动时会卡在 `_dyld_start`（进程 RSS 极小、无日志、不监听端口）。

实操处理：把二进制拷到 `/tmp`，清扩展属性并 adhoc 签名后再跑：

```bash
cp ./bin/memorystore /tmp/memorystore-clean
xattr -c /tmp/memorystore-clean
codesign --force --sign - /tmp/memorystore-clean
```

不要直接依赖 `./start.sh` 的自动 `go build`：若本机缺网或 toolchain 下载失败，启动会中断。

### 5.3 启动

```bash
cd /Users/fengtianyu/Projects/MemoriesStore/server
mkdir -p ./run /Volumes/Library/MemoriesStore

# 可选：使用仓库内 start-prod.sh（若已放置）
# ./start-prod.sh

nohup /tmp/memorystore-clean -config ./configs/config.example.yaml \
  > ./run/server.log 2>&1 &
echo $! > ./run/memorystore.pid
```

启动成功日志应类似：

```text
MemoryStore server listening addr=0.0.0.0:10002
  data=/Users/fengtianyu/Projects/MemoriesStore/server/data
  media=/Volumes/Library/MemoriesStore
```

并在外接盘下自动创建：

```text
/Volumes/Library/MemoriesStore/originals
/Volumes/Library/MemoriesStore/derivatives
/Volumes/Library/MemoriesStore/tmp
```

停止：

```bash
kill "$(cat ./run/memorystore.pid)"
# 或
pkill -f memorystore-clean
```

推荐直接用仓库脚本（`start.sh` 会自动拷到 `/tmp`、清 quarantine 并 adhoc 签名）：

```bash
./stop.sh
./start.sh
```

不要再直接 `nohup ./bin/memorystore ...`；若进程存在但不监听端口，多半是 Gatekeeper 卡住，先 `./stop.sh` 再 `./start.sh`。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 进程在跑但不监听 10002，日志为空 | Gatekeeper / quarantine | `xattr -c` + `codesign`，或拷到 `/tmp` 再启动 |
| `go build` 超时 | 访问 `proxy.golang.org` 失败 | `GOPROXY=https://goproxy.cn,direct` |
| `requires go >= 1.26.0` | 本机 Go 偏旧 | `GOTOOLCHAIN=go1.26.0` 或升级 Go |
| 公网 `curl` 超时，本机 health 正常 | 云安全组未放行映射端口 | 放行 `10002/tcp`（或你配置的 `remotePort`） |
| 改完 `frpc.toml` 无效果 | 旧 frpc 未加载新配置 | 重启 frpc（LaunchDaemon 会自动拉起） |
| `media_root` 目录仍为空 | 旧二进制不支持该配置 | 重新 `go build` 后再启动 |
| SSH 突然断开 | 重启了 frpc | 等几秒重连即可 |

## 9. 代码同步建议

当前开发机与 iMac 上各有一份目录时，推荐：

1. **长期**：两边都用 Git，经 GitHub/GitLab `push` / `pull`
2. **发版到 iMac**：`rsync` 经 FRP SSH 单向推送（排除 `data/`、`run/`、`bin/`）

示例（在开发机执行）：

```bash
rsync -avz \
  --exclude '.DS_Store' \
  --exclude 'server/data/' \
  --exclude 'server/run/' \
  --exclude 'server/bin/' \
  -e 'ssh -p 6000' \
  ./ \
  fengtianyu@120.48.22.80:/Users/fengtianyu/Projects/MemoriesStore/
```

同步代码后若 Go 源码有变，在 iMac 上重新编译并重启服务（见第 5 节）。
